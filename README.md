
# Online E-Commerce Website

A PHP and MySQL based E-Commerce Website developed using HTML, CSS, JavaScript, PHP and MySQL.

## Features

### Customer Features
- User Registration and Login
- Product Browsing
- Shopping Cart
- Add and Remove Products
- Update Product Quantity
- Checkout System
- Cash on Delivery
- Order Confirmation
- Customer Order Tracking

### Admin Features
- Admin Authentication
- Admin Dashboard
- Add Products
- Edit Products
- Delete Products
- Manage Orders
- Update Order Status
- Manage Admin Accounts

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP
- phpMyAdmin

## Installation

1. Install XAMPP.
2. Clone or download this repository.
3. Copy the project folder into `xampp/htdocs/`.
4. Start Apache and MySQL.
5. Create a MySQL database named `ecommerce1`.
6. Import your database schema.
7. Create `includes/db.php` using your local database credentials.
8. Open the project in your browser:

http://localhost/ecommerce/

## Project Structure

- admin/ - Admin dashboard and management
- includes/ - Database connection and authentication
- pages/ - Customer pages
- images/ - Product images
- css/ - Stylesheets
